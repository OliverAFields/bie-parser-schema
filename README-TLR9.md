Contains the code to perform computational modelling and receiver operating characteristic analysis for Kennedy et al.

Download all code as a zip file and run NFkBModelWithDynamicTLR.ipynb to perform modelling, or roc/rocAnalysis.ipynb as jupyter notebooks to perform the respective analysis.
